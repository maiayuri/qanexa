# QAnexa

Organize a rotina. Investigue a qualidade.

Aplicação web com lembretes, tarefas, estudos, Pomodoro, hábitos e biblioteca de materiais. Projeto acadêmico desenvolvido com apoio de IA generativa e avaliado por testes manuais. Não foram adicionados testes automatizados.

**[Abrir aplicação](https://maiayuri.github.io/qanexa/)** · **[Ler a entrega final](entrega/QAnexa_Relatorio_Final.pdf)**

## O trabalho de QA

Usamos teste exploratório para investigar os fluxos e análise de valor-limite para verificar as fronteiras das entradas.

O relatório reúne os cinco itens da atividade: técnicas, artefatos, execução, defeitos e aprendizados. Apresenta 27 casos de valor-limite com resultado conclusivo (25 passaram e 2 falharam), os registros exploratórios e sete cenários complementares (cinco passaram e dois falharam). São 11 defeitos registrados, incluindo perda de dados entre abas e validação tardia de links. Os números descrevem os cenários documentados, sem representar cobertura integral da aplicação.

Os [prints das evidências](entrega/evidencias/) também estão disponíveis separadamente. Os registros apresentam o comportamento da versão testada; o código da aplicação foi preservado nesta entrega.

## Como usar

Acesse o link da aplicação ou abra `index.html` em um navegador. Os dados ficam no navegador utilizado. A aplicação não sincroniza registros entre dispositivos.
